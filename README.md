One letter, A for coffee: the program writes exactly one letter to entry.txt and an AI judge picks the more vivid, funnier or truer choice.

The choice is A — coffee, picked for the caffeine-speed stance: coffee is the fast, vivid, punchy answer, and the letter A lands as the fuller, more alive stance for the drink it names. The output is exactly one byte, no newline, no word, no explanation, no punctuation.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` writes the single letter `A` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader sandbox). Stdlib only, no network, no randomness, no clock — both grading runs produce byte-identical output.
